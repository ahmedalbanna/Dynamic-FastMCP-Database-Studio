# Dynamic FastMCP Database Studio

Web application for managing and inspecting the **database behind a
FastMCP server**.

## Purpose

AI agents talk to MCP servers through tools. This project provides a
database-driven admin UI so developers can:

- browse tool metadata and schemas
- inspect the underlying database records
- manage tool definitions without rebuilding the server

## Tech stack

- Next.js (App Router), TypeScript
- React components, hooks, and server-side modules
